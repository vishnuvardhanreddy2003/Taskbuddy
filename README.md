# Responsive Webpage using Flexbox & CSS

This project is  built using **CSS Flexbox**


- **Responsive Navigation Bar**: Automatically adjusts for mobile devices.
- **Flexbox Layout**: Used for easy alignment and spacing.
- **Optimized for All Screens**: Works on desktop, tablet, and mobile.
- **Dropdown Menu for Mobile**: Ensures accessibility on smaller screens.
- **Cards & Buttons**: Styled for a modern UI.

Technologies Used
- **HTML5**
- **CSS3 (Flexbox & Media Queries)**
